sal

“sal” é uma ferramenta de uso pessoal. Ela usa o programa rclone para copiar os arquivos de uma única pessoa para o Google Drive dessa mesma pessoa, como cópia de segurança.

Não é um serviço público, não tem outros usuários e não está disponível para terceiros.

Política de privacidade

“sal” is a personal-use tool: it uses rclone to back up one person’s own files to that same person’s Google Drive. It is not a public service. Privacy policy.
